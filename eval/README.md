## 评测：怎么知道它变好了

### 为什么做评测

LLM 应用「感觉更好了」不算数，需要一个**可复现的数字**。

### 评测集

- 20 题三类：`in_kb` 8 / `should_refuse` 8 / `boundary` 4
- 每题含**可编程判定**的 `expected`（`must_include` / `must_include_any` / `refuse` / `need_boundary_statement`）+ `golden_ids`（该题必需的知识块 id）
- 位置 `eval/questions.jsonl`；形式红测 `eval/check_questions.py`

### 五个运行指标与口径

| 指标 | 定义 | 分母口径 |
|---|---|---|
| `recall@k` | 该题**必需的知识块**（`golden_ids`）是否**全部**出现在召回的 top-5 中 | 全部 `in_kb` 题；**未走知识库检索（`retrieved_ids` 为空）记 0**；另附「仅检索题」对照口径 |
| 拒答准确率 | 该拒的拒了 + 该答的答了 | **总题数** |
| 无据作答率 | `in_kb` 题中**给出了回答但未命中资料关键点**的比例（**代理指标**，非真实幻觉率） | **非拒答的 `in_kb` 题** |
| P50 / P95 | 延迟中位数与长尾（**不是平均值和最大值**） | 每组 60 次请求（3 轮 × 20 题）池化 |
| 平均 token | 单次请求的平均输入 / 输出 token（分开记——两者诊断方向不同） | 同组全部请求 |

### 工具链（都能一条命令跑）

| 做什么 | 命令 | 产出 |
|---|---|---|
| 跑评测 | `python eval/run_eval.py 20 r1` | `runs_r1.csv`（17 列原始数据） |
| 判据自测 | `python eval/test_judge.py` | 判据红测结果 |
| 出报告 | `python eval/summarize.py` | `report.md` |
| 做对照 | `python eval/compare_ab.py` | A/B 对比表 |
| 重判历史 | `python eval/rejudge.py` | 判据改动后重判——**不必重跑模型** |

### 关键结论（真实数据，每组 3 轮 × 20 题）

| 指标 | **A 组**（移除 `pet_care`） | **B 组**（全部工具） | 差异 |
|---|---|---|---|
| 逐轮通过率 | 95% / 100% / 100% | 80% / 90% / 70% | — |
| **通过率均值** | **98.3%** | 80.0% | **+18.3 pt** |
| **极差（方差代理）** | **5 pt**（σ 2.4） | **20 pt**（σ 8.2） | **−15 pt** |
| **检索发生率** | **98.3%**（59/60） | 76.7%（46/60） | **+21.6 pt** |
| **`recall@k` 主口径** | **100%**（24/24） | 66.7%（16/24） | **+33.3 pt** |
| `recall@k` 仅检索题 | 100%（24/24） | 100%（16/16） | 0 |
| 平均 token（输入） | 2053 | 2127 | −74 |
| P50 / P95 延迟 | 1870 / 2390 ms | 1518 / 2001 ms | **+352 / +389 ms** |
| 出现过失败的题 | 仅 `q006` | 6 道 | — |
| 通过率 95% 置信区间 | [91.1%, 99.7%] | [68.2%, 88.2%] | **不重叠** |

**怎么读这张表**：重点不是"数字更好看"，而是**四个独立指标同向变化、指向同一条机制**——

> 移除 `pet_care` → 模型改走 `search_knowledge` → 检索发生率 ↑ → `recall@k` ↑ → 通过率 ↑、方差 ↓

代价是 **P50 延迟 +352 ms**（多一次检索往返），但输入 token 反而略降（少了一个工具的 schema）。

**而且只解决了一半**：A 组唯一的失败 `q006` 仍是「**零工具调用 + 无据声称知识库里没有**」。

> 「让信息来源只有一处」修好了**工具冲突**，但对「**不查就宣称没有**」无效——这两类问题必须分别修。

### 已知限制

- **天花板效应**：A 组 98.3%（59/60）——这套题对**已修复的系统已接近失去区分度**，继续优化需先扩充评测集
- **样本量**：60 次里 1 次失败，95% 置信区间 [91.1%, 99.7%]——「A 优于 B」**方向可信**，但 **98.3% 不可当精确值引用**
- **时间混淆**：B 组评测于 2026-10-03、A 组于 2026-10-07，被测模型是**在线服务**，可能已更新——差异无法 100% 归因于工具集（更严谨的做法是 A/B 交替跑）
- **无据作答率是代理指标**（以「未命中资料关键点」近似），已对全部 5 条人工抽查并追查到根因
- **温度配置**：未设置 = 生产默认温度 1.0 —— 三轮之间的差异**就是真实方差**
